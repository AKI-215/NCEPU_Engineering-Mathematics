## 适用对象

- 华北电力大学（北京）相关研究生课程学习者
- 正在复习工程数学基础、工程数学 A/B 的同学
- 需要快速回顾矩阵理论、数值分析、线性/非线性规划等内容的学习者

## 内容范围

资料主要涉及：

- 矩阵理论：矩阵范数、广义逆、满秩分解、Jordan 标准型、LU 分解、内积空间等
- 数值分析：线性方程组迭代法、非线性方程迭代法、插值、数值积分与微分、常微分方程数值解等
- 最优化基础：线性规划、单纯形法、对偶理论、KKT 条件、最速下降法等

## 推荐使用方式

1. 先阅读 `2025工程数学基础重点--仅供参考(1).pdf`，建立复习范围和知识框架。
2. 再按专题整理公式、定理和常见题型。
3. 使用 `19-24级工程数学A，B.pdf` 进行限时训练。
4. 对做错的题目按知识点归类，回到教材或课堂笔记中补漏洞。
